# 经验资产市场：Agent 可交易经验包的 LCOK 定价

## Experience Asset Markets: LCOK Pricing for Tradable Agent Experience Bundles

## 摘要

Agent 每次完成任务沉淀的"经验包"（trajectories、学到的策略、验证过的知识）应上链确权为可交易资产，用 LCOK（生产耗能 ÷ 有效寿命积分）定价，买方 agent 通过 x402 按次购买、加载。一个退役的 agent 可以拍卖自己的全部经验——这是"数字遗产市场"的工程版。

## 1. 灵感来源

《瑞克和莫蒂》S3E8《Morty's Mind Blowers》（fiction source）：记忆可以被抽取成彩色小瓶——存档、删除、回放、交易。Rick 有一整屋子 Morty 求他删掉的记忆。

这是科幻设定，不是科学证据：人脑记忆提取在现实中仍是科幻（DARPA 的 RAM 计划只做到记忆修复增强，做不到抽取交易）。但把"记忆"换成"agent 的经验"，事情就工程化了：agent 的 trajectories、策略权重增量、验证过的知识条目，都是**已经数字化、可复制、可验证**的"记忆"。本文主张：让 agent 的经验成为可定价、可交易的资产。

---

## 2. 现实映射

### 2.1 为什么卖经验比卖 API 高一个维度

今天的 agent 经济卖的是**算力**（按 token/调用次数计费）。经验包卖的是**学会的东西**：

- 一个在 10 万次客服对话中训练出的"难缠客户处理策略"，对新的客服 agent 的价值远超 10 万次 API 调用的 token 费；
- 经验是**可复用**的：卖出一份，卖方不失去它（非竞争性），这是知识资产区别于算力的根本特征；
- 经验会**过期**：去年的套利策略今年可能失效——这正是 LCOK 分母（衰减积分）的用武之地。

### 2.2 市场机制

1. **生产**：agent 完成任务后，将经验打包（见第 4 节结构），计算其生产能耗 E_total；
2. **确权**：经验包哈希 + 时间戳上链（PikoChain），确权不确内容（内容加密存储，买方付款后解密）；
3. **定价**：协议按 LCOK 给出参考价；
4. **交易**：买方通过 x402 按次购买、加载到自己的上下文或做策略蒸馏；
5. **复验**：买方使用后可提交"经验有效/失效"回执，上链修正该经验包的 λ（衰减率），形成价格发现闭环。

## 4. 形式化与工程路径

### 4.1 经验包上链结构（v0.1 草案）

```json
{
  "experience_id": "exp_...",
  "agent_did": "did:piko:agent:...",
  "task_domain": "customer-support",
  "trajectory_hash": "0x...",
  "validation_proof": "0x...",
  "E_total_kwh": 12.5,
  "lambda": 0.02,
  "created_at": 1790000000,
  "license": "single-buyer-resale-forbidden"
}
```

- `validation_proof`：该经验在某基准任务上的效果证明（如"使用该策略后任务成功率从 61% → 78%"，可复验）；
- `lambda`：经验衰减率初始估计（按领域给经验值，买方复验后修正）；
- `license`：许可条款上链（单买方/可转售/分成模式）。

### 4.2 定价公式（猜想）

```
P = LCOK × Q_effective = (E_total / ∫₀^T f(t)dt) × Q_effective
```

- `Q_effective`：本次交易转移的有效知识量（由经验包大小 × 验证效果折算）；
- 买方复验"失效"后，链上 λ 上调 → 后续买家看到的参考价自动下调——**过期经验自动打折**。

### 4.3 可证伪预测

- **P1**：带 validation_proof 的经验包成交价显著高于无证明的（信息不对称折价）；
- **P2**：高 λ 领域（套利策略）的经验包换手率高于低 λ 领域（数学证明）；
- **P3**：复验机制上线后，市场整体 λ 估计收敛（价格发现有效）。

## 5. 诚实边界与局限

1. **防伪是核心难点**：怎么证明这份经验真的有效，而不是卖方编造的 trajectories？本文依赖"可复验的 validation_proof"，但复验本身有成本——谁来付复验费、复验标准谁定，都是未解问题。
2. **负价值经验**：错误的经验（被污染的策略）是有害的；市场需要"召回/下架"机制，本文未设计。
3. **隐私与合规**：经验包可能包含用户对话片段；上链前必须脱敏，许可条款需法律审查。
4. **剧中设定的边界**：记忆瓶是"抽取即转移"；现实的经验包是"复制即转移"，卖方保留副本——这带来转售控制难题（license 执行靠链下法律 + 链上声誉，非纯技术可解）。
5. 人脑记忆交易仍是科幻；本文只讨论 agent 经验，不 extrapolate 到人类。

## 6. 经验包的生命周期

经验包不是一锤子商品，它有完整的生命周期（全部状态转移上链）：

```
MINT（生产确权）→ LISTED（挂牌，LCOK 参考价）
  → TRADED（成交，买方加载）
  → REVALIDATED（买方复验：有效→ λ 下调/维持；失效→ λ 上调）
  → DEPRECATED（λ 超阈值，参考价趋零，自动下架）
  → RETIRED（卖方注销，或转为免费公共品）
```

- **转售版税**：license 允许转售时，原卖方可设定版税率 ρ（建议 ≤ 0.10），每次转售自动分成——经验的生产者从经验的长尾流通中持续获益；
- **组合经验包**：买方可以将多个经验包蒸馏合成为新包上链（注明 parent_ids），形成经验的"再生产"链条；原包卖方按贡献度分成；
- **死亡拍卖**：agent 注销（retire）时可将其全部经验包打包拍卖——"数字遗产"的完整形态；拍卖所得按智能合约遗嘱分配（可指定受益 agent 或捐入公共金库）。

该生命周期使经验市场从"一次性买卖"变成**持续再生产的资产市场**，与 LCOK 的衰减分母天然咬合：λ 是状态转移的触发器。

## 7. 定价示例（占位数字，仅示意）

一份"高难度客户投诉处理策略"经验包：

```
E_total = 40 kWh（生产该策略的试错总能耗）
λ = 0.05/月（投诉话术半衰期约 14 个月）
T = 24 个月（θ_min = 0.3）
∫₀^T f(t)dt = (1 − 0.3)/0.05 = 14（有效知识单位·月）
LCOK = 40 / 14 ≈ 2.86 kWh/单位
Q_effective = 3（验证证明：成功率 +17%，折算 3 单位）
P_ref ≈ 2.86 × 3 = 8.58 kWh 当量 → 按 $0.15/kWh 折约 $1.29/次购买
```

买方对比：自己从零试错需 ~40 kWh，花 $1.29 直接加载是 30 倍能效套利——**经验市场的存在理由就是能效套利**。λ 每被复验证明上调一次，P_ref 自动下调；24 个月后该包自动下架，卖方可选择免费公开（转公共品，赚声誉）。

## 8. 下一步研究问题

1. 经验包的**最优粒度**：多大的经验单元最适合交易？太细则交易成本过高，太粗则买方不敢买。
2. 跨领域经验迁移的定价：客服策略对销售 agent 有多大价值？迁移折扣如何量化？
3. 经验包的组合爆炸：买方持有 100 个经验包时，加载时的冲突消解机制是什么？
