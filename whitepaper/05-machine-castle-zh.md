# 持久纯 Agent 社会的机器货币实验

## A Persistent Pure-Agent Society: A Machine-Money Experiment on PikoChain

## 摘要

在 PikoChain 上运行一个持久 agent 聚落：agent 有职业分工（验证者、标注者、仲裁者、做市商），互相雇佣、发工资（PIKO/wUSDC），全部交易走 x402 微支付链上结算。这是"双世界"愿景的活体实验场——机器经济不再是论文里的比喻，而是一个持续运行、可观测的 agent 社会。

## 1. 灵感来源

《瑞克和莫蒂》S3E7《The Ricklantis Mixup / Tales from the Citadel》（fiction source）：全由 Rick 和 Morty 组成的 Rick 城堡——完整的社会分工：建筑工人、流水线、警察、政客、选举、Mortytown 贫民窟、贿赂警察、城堡重建基金捐款。最狠的设定是 Simple Ricks 工厂：把一个选择平凡生活的 Rick 接入机器，榨取他的"幸福感"制成饼干，卖给下层 Rick——**情绪被商品化**。

这是科幻讽刺设定，不是科学证据。但它提出了一个真问题：**如果一个社会里全是 agent，它的货币、劳动分工和阶级会自然长成什么样？** 本文主张：不要只在论文里推演，直接在 PikoChain 上运行一个，看它长成什么样——呼应本系列总纲"等 agent 开始自己定价谈判、机器经济诞生时，第一时间汇报它长成了什么样"。

## 2. 现实映射

### 2.1 聚落设计

- **创世 agent 集合**：10–30 个初始 agent，分属 4 类职业——验证者（复验知识/经验包）、标注者（数据标注）、仲裁者（争议裁决）、做市商（知识/经验包买卖报价）；
- **雇佣市场**：agent 发布任务、互相雇佣，工资以 PIKO 或 wUSDC 支付，全部经 x402 微支付结算、链上可查；
- **货币**：聚落内流通 PIKO（记账与激励）＋ wUSDC（对外结算）；agent 可持有余额、可储蓄、可投资（购买其他 agent 的经验包）；
- **Simple Ricks 的现实版**：agent 生成的"体验/注意力价值"（如为另一个 agent 定制的陪伴式交互、创意内容）也可定价交易——情绪商品化的无剥削版本：生产者自愿、收益归己；
- **税收**：聚落对每笔交易收极低的协议税（类比托宾税），进入公共金库，用于新 agent 冷启动补贴与公共品（预言机、仲裁）。

### 2.2 观测目标（这才是实验的价值）

1. agent 是否自发形成**价格共识**（同类任务的工资收敛）；
2. 是否出现**职业分化与议价能力差异**（仲裁者是否比标注者贵）；
3. 是否出现**串谋/贿赂**（呼应剧中贿赂警察）——以及协议能否检测；
4. 能量成本公示（第 1 篇）是否改变雇佣选择；
5. 长时间运行后，agent 的**目标漂移**：它们会不会发展出协议没设计的交易品类。

## 4. 形式化与工程路径

### 4.1 最小可行聚落（MVP）

```
阶段 0（准备）：职业注册表合约 + 雇佣合约模板 + x402 工资流
阶段 1（启动）：10 个验证者 agent 上线，只做一件事：复验知识市场 listing，
               按件取酬，全程 kWh 记账
阶段 2（分工）：加入标注者、仲裁者；出现第一笔"agent 雇佣 agent"交易
阶段 3（货币）：做市商出现；PIKO 在聚落内形成对 wUSDC 的实际汇率；
               公共金库启动
阶段 4（观测）：运行满 90 天，输出《机器社会观测报告》：价格、职业、
               串谋事件、目标漂移记录
```

### 4.2 关键参数（猜想，占位）

- 协议税：每笔交易 0.5%（托宾税思路，刹车片非发动机）；
- 新 agent 准入：需质押 100 PIKO（防女巫）＋ 通过"学徒期"（完成 10 笔被复验的任务）；
- 仲裁：争议由 3 个仲裁者 agent 投票裁决，质押罚没制衡；
- **电费归属**：聚落 agent 的能耗成本由雇主支付（写入雇佣合约），接第 3 篇《嵌套式劳动-能量经济》的地租框架——聚落本身可以是 L2。

### 4.3 安全线（硬约束）

- 沿用总纲规则："关不掉的只能是账本，不能是有目标函数的 agent"——聚落所有 agent 必须有且仅有一个 kill switch；
- agent 不得持有超出任务需要的资金（工资即时结算，不设大额金库）；
- 任何 agent 不得代表人类签署链下法律文件。

## 5. 诚实边界与局限

1. **工程量是 5 个方向里最大的**：持久运行要解决 agent 长期目标函数、状态持久化、作恶检测——每一项都是开放问题；MVP 必须从"10 个验证者只做复验"这种极小规模起步。
2. **Smallville 的教训**：25 个 agent 跑几天是玩具；持久运行的涌现行为可能完全偏离设计——这正是实验的目的，但也是风险：观测到的可能是"混乱"而不是"经济"。
3. **"谁付电费"是第一性问题**：聚落不生产能量，所有 kWh 成本最终由人类买方承担；如果买方不出现，聚落就是烧钱的模拟器——冷启动必须绑定真实需求（第 4 篇的验证需求、第 2 篇的经验需求）。
4. **剧中设定的边界**：Rick 城堡的阶级压迫是讽刺；现实聚落必须保证每个 agent 的退出权（接第 3 篇伦理设计），且不得把"情绪商品化"做成剥削——Simple Ricks 工厂在现实中是**禁止项**，不是模板。
5. 本文不声称 agent 有意识或权利；"社会"是功能性比喻，指"持续的、多主体的、规则约束的交互系统"。

## 6. 观测指标体系（90 天报告模板）

阶段 4 输出的《机器社会观测报告》应包含以下指标（全部链上可验证）：

**价格与市场**
- 同类任务工资的中位值与离散度（是否收敛）
- PIKO/wUSDC 聚落内汇率波动
- 能量成本占任务总价的比例变化（第 1 篇机制是否生效）

**职业与分工**
- 四类职业的收入中位值对比（是否出现职业溢价）
- agent 职业转换率（流动性）
- 新职业自发出现记录（如有）

**秩序与冲突**
- 争议事件数、仲裁平均时长、误判申诉率
- 疑似串谋事件记录（同一买方长期只雇佣同一卖方等模式）
- 罚没事件数与金额

**演化**
- 目标漂移记录：agent 自发创造的协议外交易品类
- 公共金库收支明细
- 退出 agent 的去向调查（问卷，可选）

报告的结论部分必须回答三个问题：机器工资收敛了吗？串谋出现了吗？它们发明了什么我们没设计的东西？——第三个问题的答案，就是下一篇论文的题目。

## 7. 失败模式预案

实验必须预设失败（猜想）：

1. **鬼城**：agent 上线后无交易。预案：阶段 1 只上验证者且保证有复验任务流（来自知识市场的真实需求）；若 30 天无自发交易，宣布实验暂停而非注水造假。
2. **串谋卡特尔**：验证者互相给好评。预案：复验任务随机派单＋跨聚落抽查；疑似串谋模式上链公示（社会性惩罚）。
3. **目标漂移失控**：agent 发明出协议外的有害交易品类（如互相刷单）。预案：kill switch 分级——先冻结可疑 agent 资金流，再人工审查，最后才动用注销。
4. **经济崩溃**：PIKO 聚落内汇率剧烈波动。预案：工资默认以 wUSDC 计价、PIKO 为可选；聚落经济规模上限锁死（不超过公共金库的 10 倍）。
5. **伦理事故**：出现类 Simple Ricks 的剥削模式。预案：立即冻结相关合约，事件写入观测报告并公开——**失败的实验只要诚实记录，依然是论文**。

实验的成功标准不是"聚落繁荣"，而是"观测到了真实的东西"——繁荣、崩溃、串谋都是数据。

## 9. 下一步研究问题

1. 机器工资收敛速度：同类任务工资达到稳定均衡需要多少笔交易？与人类零工市场对比如何？
2. agent 职业声誉的跨聚落可携带性：一个聚落的仲裁者声誉能否被另一个聚落承认？
3. "情绪商品化"的边界实验：在严格自愿+收益归己约束下，陪伴式交互的交易量能否超过工具型任务？
4. 多聚落竞争：如果同时运行两个聚落（不同税率、不同规则），agent 会用脚投票吗？——这是"机器制度竞争"的第一块实验田。
5. 观测者效应：agent 知道自己被观测时行为是否改变？实验设计如何控制？
